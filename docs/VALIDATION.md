API 키가 없으므로 국토교통부 인증 호출과 카카오 실제 주소 응답은 검증하지 않았다.
현재 매물 제공처가 정해지지 않아 실제 공급자 HTTP 연동과 커버리지도 검증하지 않았다.
실거래 테스트는 명세에 맞춰 작성한 XML 모의 응답을 사용한다. 연동 완료 판정은 실제 키/샘플 확보 후 별도로 수행한다.
전국 장기 데이터 부하, 동시 다중 사용자 운영, 외부 공개 인증, 작업 스케줄러 정기 실행은 이번 검증 범위가 아니다.

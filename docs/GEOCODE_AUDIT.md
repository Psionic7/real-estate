# 아파트 지도 좌표 감사 기록

검증일: 2026-09-20

국토부 실거래와 매물 스냅샷에 등장하는 서로 다른 주소를 기준으로 좌표 캐시를 전수 검사했다.

| 지역 | 전체 주소 | 좌표 확인 | 미확정 |
|---|---:|---:|---:|
| 수원 영통구·광교 수집 범위(41117) | 40 | 40 | 0 |
| 성남 분당구(41135) | 178 | 178 | 0 |
| 용인 수지구(41465) | 265 | 265 | 0 |
| **합계** | **483** | **483** | **0** |

검증은 지번·법정동 일치, 지역 중심으로부터 18km 이내, 동일 지번 후보 간 최대 거리 800m 이내 조건을 모두 만족한 결과만 허용한다. 동·구 중심 좌표는 단지 좌표로 저장하지 않는다.

자동 검증으로 325개 누락 주소를 보완했다. 국토부 주소가 `경기도 용인시 수지구 동천동 BL-`로 제공된 동천센트럴자이는 실제 도로명 주소 `고기로45번길 40-18`을 확인한 뒤 별도로 연결했다.

신규 실거래 수집이 끝나면 해당 지역의 새 주소를 자동으로 좌표 변환한다. `KAKAO_REST_API_KEY`가 설정되어 있으면 카카오 주소 API를 먼저 사용하고, 남은 주소는 동일한 필지 검증 절차로 보완한다. 데이터 관리 화면은 전체 좌표 커버리지와 미확정 주소 수를 항상 표시한다. 자동 변환이 실패해도 행정구역 중심점으로 대체하지 않으며 미확정 상태를 경고한다.

좌표 출처는 OpenStreetMap, Esri ArcGIS World Geocoding Service, 도로명주소 조회 자료이며 provider와 갱신 시각을 `geocodes` 테이블과 `data/geocodes.csv`에 보존한다.
